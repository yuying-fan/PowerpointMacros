# PowerpointMacros
This repository contains usful VBA macros for PowerPoint that I use for formatting
- These are adapted from publicly available tools and sources are listed below

### AutoSections
- **Purpose:** Automatically adds a slide progress bar, section labels across the top of slides, and highlighting on the current section
- **Usage:** In the first line of slide notes, add "Section:[Slide Title]". Only add this to the first slide of each section. Note that the progress bar is based on total number of slides in the powerpoint
- **Source:** https://github.com/eric-guerin/powerpoint-progressbar/blob/master/README.md
